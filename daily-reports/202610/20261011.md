# 2026-10-11

## Authentik の MFA をメール OTP に移行

- パスワードログインの MFA を TOTP / WebAuthn（パスキー）からメール OTP のみに切り替えた（PR #3）
- メール送信サーバーがないため、テスト用 SMTP として Mailpit を namespace mailpit に追加し、authentik のグローバルメール設定の送信先にした
- authentik 2026.8.3 の default blueprint にはメール OTP の登録用 flow がないため、MFA 用 blueprint 内で登録用 flow と Email Authenticator ステージを定義した
- blueprint 名と ConfigMap 名は据え置き、既存クラスタで同じ blueprint として上書きされるようにした
- 既存ユーザーの TOTP / WebAuthn デバイスは DB に残すが、validation では使わない
- マージ前に kind クラスタへ直接反映し、caddy-demo 経由で akadmin がメール OTP を登録してログインできることを確認した

### 申し送り

- blueprint の ConfigMap を更新した後、blueprint mfa-required は successful のまま新しい内容が自動で反映されず、ak apply_blueprint で手動で再適用した。README の「worker を再起動すれば再適用される」という記載では足りない可能性がある
- この kind クラスタには Flux の GitRepository / Kustomization がなく git から同期していないため、マージしても自動では反映されない
